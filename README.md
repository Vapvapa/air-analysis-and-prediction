# Air analysis and prediction
## Описание проекта
Проект содержит независимые блокноты для анализа и прогнозирования данных о составе воздуха.

## Оценка уровня загрязнения атмосферы
### assessment-level-air-pollution

Вычисляются:
- Среднегодовая концентрация (qi);
- Cмакс;
- ПДКсс (предельно допустимая концентрация среднесуточная);
- ПДКсг (предельно допустимая концентрация среднегодовая);
- Класс опасности (m);
- Суммарный индекс загрязнения атмосферы;
- Уровень загрязнения;
- Индекс загрязнения, приведенный к 3-му классу опасности;
- Комплексный показатель (P);
- Показатель опасности (По);
- Парциальные индексы (Ii = (qi/ПДКсг)^m).

Построены графики:
- Парциальных индексов;
- (qi / ПДКсг) для сравнения;
- Сравнение ПДКсс и ПДКсг;
- Временные ряды концентраций с ПДК.

Также вычисляются метеорологические показатели:
- Повторяемость дней со штилем;
- Повторяемость дней с туманами;
- Повторяемость дней со скоростью ветра >= 6 м/с;
- Повторяемость дней с осадками >= 0.5 мм;
- Коэффициент самоочищения атмосферы;
- Характеристика условий рассеивания.

## Вычисление статистических выбросов и резких изменений погодных условий
### calculation-data-outliers-and-weather-anomalies

Выбросы рассчитывались методом IQR.

Метод IQR (Interquartile Range, межквартильный размах) основан на разнице между третьим (Q3) и первым (Q1) квартилями:

IQR = Q3 - Q1.

Значения считаются выбросами, если они выходят за пределы интервала [Q1 - 1,5 × IQR; Q3 + 1,5 × IQR].

Резкими изменениями погодных условий считались выбросы, которые с определённой погрешностью по времени и по значению совпадали хотя бы в 2 из 3 файлов.

## Расчёт общего индекса качества воздуха (ОИКВ) и построение таблицы распределения ИКВ по классам для каждой станции
### calculation-overall-air-quality-index-and-table-for-stations

Код написан на основе работы «Расчет индекса качества воздуха и оценка его информативности для российских условий по данным мониторинга в Москве» И. Н. Кузнецова, Ю. В. Ткачева, И. Ю. Шалыгина, Е. А. Лезина: https://elibrary.ru/download/elibrary_46708413_18595101.pdf.

ИКВ рассчитывается по таблице 2 (ЕС).

## Предсказание значений индекса качества воздуха (ИКВ) с помощью машинного обучения (классификация)
### prediction-air-quality-index-ml-classification

Используемые модели:
1. RandomForestClassifier;
2. LogisticRegression;
3. KNeighborsClassifier;
4. XGBoost;
5. LightGBM;
6. CatBoost.

В блокноте реализован расчёт качества моделей по стандартным метрикам.

## Предсказание значений диоксида азота (NO2) с помощью машинного обучения (регрессия)
### prediction-no2-ml-regression

Используемые модели:
1. RandomForestRegressor;
2. ElasticNet;
3. HistGradientBoostingRegressor;
4. ExtraTreesRegressor;
5. XGBoost;
6. LightGBM.

В блокноте реализован расчёт качества моделей по стандартным метрикам. Проект также позволяет анализировать значимость предикторов (временные лаги, метеоданные, пространственные признаки и др.). Целевую переменную можно изменить, указав нужное название столбца в переменной `TARGET`.

## Инструкция по запуску
1. Клонируйте репозиторий: `git clone https://github.com/Vapvapa/air-pollution-ml`
2. Откройте в Google Colab, Anaconda Navigator или другой среде выполнения.
3. При необходимости настройте путь к данным (`filenames`) и требуемую целевую переменную (`TARGET`).
4. Запустите нужный блокнот:
    - `assessment-level-air-pollution` — оценка уровня загрязнения атмосферы;
    - `calculation-data-outliers-and-weather-anomalies` — вычисление статистических выбросов и резких изменений погодных условий;
    - `calculation-overall-air-quality-index-and-table-for-stations` — расчёт общего индекса качества воздуха (ОИКВ) и построение таблицы распределения ИКВ по классам для каждой станции;
    - `prediction-air-quality-index-ml-classification` — предсказание значений индекса качества воздуха (ИКВ) с помощью машинного обучения (классификация);
    - `prediction-no2-ml-regression` — предсказание значений диоксида азота (NO2) с помощью машинного обучения (регрессия).
