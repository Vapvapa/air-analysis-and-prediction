# Air-pollition-ml
## Описание проекта
Проект содержит набор инструментов для прогнозирования концентраций загрязняющих веществ в атмосферном воздухе с использованием методов машинного обучения. Реализован сравнительный анализ моделей и детальная оценка их качества.

## Функциональность
Проект позволяет:
* обучать 7 моделей машинного обучения для прогнозирования концентраций загрязнителей;
* сравнивать эффективность моделей по стандартным метрикам качества;
* анализировать значимость предикторов (временные лаги, метеоданные, пространственные признаки и др.);
* прогнозировать концентрации ключевых загрязнителей

## Доступные модели ML
В проекте реализованы:
* ```RandomForestRegressor```
* ```ElasticNet```
* ```HistGradientBoostingRegressor```
* ```ExtraTreesRegressor```
* ```XGBoost```
* ```LightGBM```

## Метрики оценки качества
Для оценки моделей используются:
* __MAE__ (средняя абсолютная ошибка);
* __RMSE__ (среднеквадратичная ошибка);
* __R²__ (коэффициент детерминации).

## Системные требования
Для работы приложения необходимы:
* Java Development Kit (JDK) версии 19 или выше;
* среда разработки (IDE) с поддержкой Java (например, IntelliJ IDEA, Eclipse);
* доступ к репозиторию на GitHub/GitLab ([https://github.com/Vapvapa/air-pollution-ml](https://github.com/Vapvapa/air-pollution-ml)).

## Инструкция по запуску
1. Клонируйте репозиторий: ```git clone https://github.com/Vapvapa/air-pollution-ml ```
2. Откройте проект в Google Collaboratory ([https://colab.research.google.com/](https://colab.research.google.com/)) или в Anaconda Navigator (предварительно установив).
3. Настройте путь к данным (```filenames```) и требуемую целевую переменную (```TARGET```).
4. Запустите нужный проект:
    * ```no2-prediction-model-comparison.ipynb``` — для сравнения моделей машинного обучения для одной целевой переменной;
    * ```co-random-forest-detailed-analysis.ipynb``` — для детального анализа одной модели машинного обучения, обученной для одной целевой переменной.
